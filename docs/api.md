# مرجع API دستیار

آدرس پایه: `https://SUB_DOMAIN:2053` (دامنهٔ پشت کلادفلر). همهٔ درخواست‌ها هدر `X-Token: <API_TOKEN>` می‌خواهند؛ بدون آن پاسخ `404` است.
پاسخ‌ها JSON‌اند. خطا: `{"error": "..."}` با کد 400 (ورودی نامعتبر) یا 502 (خطای پنل).

## کاربران
| روش و مسیر | بدنه | کار |
|---|---|---|
| `GET /v1/users` | — | فهرست کاربران با مصرف، انقضا، آنلاین‌بودن، لینک اشتراک و `summary` |
| `POST /v1/users/create` | `{"name","gb","days","limitIp","comment"}` | ساخت کاربر روی هر دو اینباند. نام: حروف انگلیسی، عدد و `- _ .` (تا ۳۲). `gb=0` نامحدود، `days=0` بدون انقضا |
| `POST /v1/users/update` | `{"email", "gb"\|"addGb", "setDays"\|"addDays", "enable", "limitIp", "comment", "resetTraffic"}` | ویرایش |
| `POST /v1/users/delete` | `{"email"}` | حذف همراه با مصرف |

## سرور و مقصدها
| روش و مسیر | کار |
|---|---|
| `GET /v1/server` | پردازنده، رم، دیسک، ترافیک امروز و کل، اتصال همزمان، گواهی و کارت هر اینباند |
| `GET /v1/targets` | سایت‌های استتار و سلامتشان از روی سرور |
| `POST /v1/targets/set` | `{"inbound": ID, "host": "www.example.com"}` تعویض دستی (باید TLS1.3 و h2 داشته باشد) |
| `POST /v1/heal` | تعویض فوری مقصدها با نفر بعدی سالم |
| `POST /v1/server/restart` | راه‌اندازی مجدد x-ui |
| `POST /v1/server/backup` | دیتابیس 3x-ui (base64) |
| `POST /v1/server/cert` | بررسی/تمدید گواهی |

## DNS (کلادفلر)
| `GET /v1/dns` | رکوردها و آی‌پی واقعی سرور |
| `POST /v1/dns/update` | `{"ip": "1.2.3.4"}` هر دو رکورد را عوض می‌کند (پراکسی هر رکورد حفظ می‌شود) |

## هشدارها
| `GET /v1/events?since=N` | رویدادهای تازه‌تر از شناسهٔ N |

## مهاجرت
| روش و مسیر | کار |
|---|---|
| `POST /v1/migration/bundle` | ساخت و دریافت بستهٔ رمزگذاری‌شده (base64) و رمزش |
| `GET /v1/migration/key` | رمز بسته و دستور بازیابی |
| `POST /v1/spare/start` | `{"host","password"}` نصب روی سرور یدک در حالت آماده‌باش |
| `GET /v1/spare` | وضعیت و گزارش |
| `POST /v1/spare/promote` | فعال‌سازی سرور یدک و تغییر DNS |
